## 6. Récapitulatif des notions essentielles (fidèle au cours)

- Chapitre II « Les composés du vivant » : 1. Les atomes du vivant ; 2. L'eau ; 3. La chimie du carbone ; 4. Les macromolécules.
- Éléments du vivant (légende du tableau périodique, p.9) : carbone, oxygène, hydrogène, azote, sodium, chlore, calcium, phosphore, potassium, soufre, fer, magnésium.
- Atomes chez l'homme (% du poids total) : O 65,0 ; C 18,5 ; H 9,5 ; N 3,3 (ces quatre = 96,3 %) ; Ca 1,5 ; P 1,0 ; K 0,4 ; S 0,3 ; Na 0,2 ; Cl 0,2 ; Mg 0,1 ; Fe < 0,1 ; Zn et I : traces.
- Carence en iode : crétinisme, retard de croissance, déficiences mentales ; fréquente dans les Alpes jusqu'au début du XXe siècle (sel de gemme pauvre en iode) ; manque d'hormones thyroïdiennes, qui nécessitent la présence d'atomes d'iode.
- Liaisons : covalente = partage de paires d'électrons (+++) ; ionique = attraction de charges opposées (++) ; hydrogène = partage d'atome d'hydrogène (+).
- Réactions : réactifs → produits. Photosynthèse : 6 H2O + 6 CO2 → C6H12O6 + 6 O2 (lumière). Respiration cellulaire : C6H12O6 + 6 O2 → 6 H2O + 6 CO2 (énergie).
- La vitesse d'une réaction chimique est influencée par : 1. la température ; 2. la concentration des réactifs et produits ; 3. la présence de catalyseurs (enzymes).
