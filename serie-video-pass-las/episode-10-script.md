## 6. Récapitulatif des notions essentielles (fidèle au cours)

- Chapitre III, structure de la cellule eucaryote : 1. Introduction ; 2. Eucaryotes vs procaryotes ; 3. Le noyau ; 4. Le système membranaire interne ; 5. Mitochondries ; 6. Le cytosquelette ; 7. Structures extra-cellulaires ; 8. Interactions cellulaires.
- 1665 : Robert Hooke décrit des « cellulae » (petites chambres) en observant un fragment de liège au microscope.
- Théorie cellulaire : tous les organismes sont constitués d'une ou plusieurs cellules ; les cellules sont les unités vivantes de base ; les cellules dérivent toujours d'une cellule préexistante (divisions cellulaires).
- Dimension des cellules : typiquement 10 – 100 µm de diamètre ; facilite la diffusion de substances extérieur ↔ intérieur ; rapport surface/volume élevé.
- Microscopes : photonique (lumière ; résolution 200 nm ; colorants, marqueurs spécifiques fluorescents) ; électronique (faisceau d'électrons ; résolution 0,2 nm ; à transmission, à balayage).
- Cellule eucaryote : cytoplasme, membrane plasmique, organites, noyau, enveloppe nucléaire.
- Procaryotes : bactéries et archées ; 1 à 8 µm ; pas de compartiments internes ; pas de noyau ; paroi rigide (en option). Cellule animale : nombreux compartiments (réseau de membranes intracellulaires) ; exécution simultanée de processus biochimiques variés (indépendants) ; réseau de protéines internes (cytosquelette) → structure ; le tout baignant dans le cytosol (liquide gélatineux).
