|---|---|
| **A. Durée** | 41 s (00:57 → 01:38) |
| **Source** | S1-1 p.19 — diapo `S1-1:19b` |

**B. Voix off**

> Sur le squelette C H se greffent des **groupes fonctionnels**, qui impliquent d'autres atomes : oxygène, azote, soufre, phosphore. Le cours en présente six.
>
> Un : l'**hydroxyle**, ou alcool, O H. Exemple : l'éthanol. Présent dans les glucides, les protéines, les acides nucléiques et les lipides. Il est polaire, attire les molécules d'eau, et facilite donc la dissolution des composés organiques.
>
> Deux : le **carbonyle**, C double liaison O. Exemple : l'acétaldéhyde. Présent dans les glucides et les acides nucléiques. Il est fortement polaire.
>
> Trois : le **carboxyle**, C O O H. Exemple : l'acide acétique. Présent dans les protéines et les lipides. C'est une **source de protons**, de H plus : il a des propriétés **acides**, et devient C O O moins.
>

- **Carbonyle** C=O · acétaldéhyde · **fortement** polaire
- **Carboxyle** –COOH · acide acétique · source de H⁺ ⇒ **acide** (→ COO⁻)

|---|---|
| **A. Durée** | 27 s (02:10 → 02:38) |

**B. Voix off**

> Une personnalité par groupe.
>
> L'hydroxyle, O H : “Oh, de l'eau !” Il attire l'eau et aide à dissoudre.
>
> Le carbonyle, C double liaison O : le plus polaire du lot, “fortement polaire”.

>

>
> Le thiol, S H, est un soudeur : deux thiols se soudent en pont disulfure.
>

>

**D. Texte incrusté**

- Titre : **Six groupes, six personnalités**
- **OH** hydroxyle : « Oh, de l'eau ! » → polaire, dissolution
- **C=O** carbonyle : **fortement** polaire
- **COOH** carboxyle : **donne** H⁺ → acide
- **NH₂** amine : **prend** H⁺ → base (NH₃⁺)
- **SH** thiol : se **soude** 2 à 2 → pont disulfure

### SÉQUENCE 12 — QUATRE GROUPES DE MACROMOLÉCULES BIOLOGIQUES  ·  *LA DIAPO DU COURS*

| | |
|---|---|
| **A. Durée** | 69 s (03:28 → 04:37) |
| **Source** | S1-1 p.22 — diapo `S1-1:22h` |

**B. Voix off**

> Voici le tableau-clé du chapitre : quatre groupes de macromolécules, avec leur sous-unité, leur fonction et un exemple.
>
> Les **glucides** : amidon et glycogène, faits de glucose, pour le stockage d'énergie, comme dans les patates. La cellulose, faite de glucose, pour les parois cellulaires des plantes, comme les fils de céleri. La chitine, faite de glucose modifié, comme support structural, dans la carapace du crabe.
>
> Les **acides nucléiques** : l'ADN, fait de nucléotides, porte l'information, dans les chromosomes. L'ARN, fait de nucléotides, sert à l'expression de l'information, comme l'ARN messager.
>
> Les **protéines**, faites d'acides aminés : de fonction, pour la catalyse et le transport, comme l'hémoglobine ; de structure, pour le support, comme les cheveux.
>
> Les **lipides** : les triglycérides, glycérol et acides gras, pour le stockage d'énergie, comme le beurre et l'huile d'olive. Les phospholipides, glycérol, acides gras et groupes polaires, pour les membranes cellulaires, comme la phosphatidylcholine. Les prostaglandines, cycles carbonés et queues apolaires, messagers chimiques. Les stéroïdes, cycles carbonés, pour les membranes et les hormones, comme le cholestérol et l'œstrogène. Et les terpènes, chaînes carbonées, pigments et défense, comme le carotène et le latex.
>

## 6. Récapitulatif des notions essentielles (fidèle au cours)

- L'atome de carbone constitue la charpente de la majorité des molécules biologiques ; il s'associe à H, O, N, P (phosphate) et S.
- Tétravalence du carbone : chaînes simples, chaînes ramifiées, structures en anneau ; cristal de carbone = diamant.
- Hydrocarbures : formés uniquement de carbone et d'hydrogène ; liaisons C–H riches en énergie (carburants) ; liaisons C–C et C–H équilibrées ⇒ apolaires ; ex. propane (C3H8).
- Groupes fonctionnels greffés sur le squelette C–H (impliquant O, N, S, P) : hydroxyle –OH (alcool ; éthanol ; glucides, protéines, acides nucléiques, lipides ; polaire, attire l'eau ⇒ facilite la dissolution) ; carbonyle C=O (acétaldéhyde ; glucides, acides nucléiques ; fortement polaire) ; carboxyle –COOH (acide acétique ; protéines, lipides ; source de protons H+ ⇒ propriétés acides, COOH → COO– + H+) ; amine –NH2 (alanine ; protéines, acides nucléiques ; peut accepter des H+ (base), souvent ionisée, charge +1 : –NH3+) ; sulfhydryle (thiol) –SH (cystéine ; protéines ; se combinent 2 à 2 en ponts disulfure) ; phosphate –OPO3²⁻ (glycérol phosphate ; acides nucléiques ; ion de charge négative ; transfert d'énergie d'une molécule à l'autre).
- Polymère : assemblage d'une succession de petites sous-unités chimiques similaires (monomères) ; ex. amidon. Déshydratation = réaction d'assemblage (synthèse) des monomères (polymérisation) ; hydrolyse = réaction de rupture de la liaison des monomères.
- Quatre groupes de macromolécules biologiques (sous-unité / fonction / exemple) : glucides — amidon, glycogène (glucose ; stockage d'énergie ; patates), cellulose (glucose ; parois cell. des plantes ; fils de céleri), chitine (glucose modifié ; support structural ; carapace du crabe) ; acides nucléiques — ADN (nucléotides ; information ; chromosomes), ARN (nucléotides ; expression de l'info. ; ARN messager) ; protéines — de fonction (acides aminés ; catalyse, transport ; hémoglobine), de structure (acides aminés ; support ; cheveux) ; lipides — triglycérides (glycérol, acides gras ; stockage d'énergie ; beurre, huile d'olive), phospholipides (glycérol, acides gras, gr. polaires ; membranes cell. ; phosphatidylcholine), prostaglandines (cycles carbonés, queues apolaires ; messager chimique ; prostaglandine), stéroïdes (cycles carbonés ; membranes, hormones ; cholestérol, œstrogène), terpènes (chaînes carbonées ; pigments, défense ; carotène, latex).
