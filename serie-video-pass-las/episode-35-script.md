### SÉQUENCE 5 — CONSÉQUENCES D'UNE MUTATION  ·  *TABLEAU*

| | |
|---|---|
| **A. Durée** | 40 s (01:22 → 02:02) |
| **Source** | S1-3 p.29 |

**B. Voix off**

> Les conséquences sont variables.
>
> Dans la région codante, une substitution peut être sans effet sur la protéine, grâce à la dégénérescence du code. Exemple : G C C devient G C G, deux codons de l'alanine.
>
> Elle peut changer un ou plusieurs acides aminés : l'effet dépend de l'importance de ces acides aminés pour la fonction.
>
> Ou décaler le cadre de lecture, ce qui modifie beaucoup la protéine, et mène le plus souvent à une perte de fonction.
>
> Dans une région non codante, promoteur, régions non traduites, introns, les conséquences sont moins prévisibles : un changement du niveau d'expression, si un site de fixation d'un facteur de transcription est touché, ou un défaut d'épissage, près d'une jonction intron-exon.
>

## 6. Récapitulatif des notions essentielles (fidèle au cours)

- Polymorphisme : variation normale de la séquence d'ADN au sein d'une espèce ; chez l'homme, 1 nucléotide sur 1250 diffère entre deux individus (2,5 × 10⁶ différences) ; 99,9 % identique, 0,1 % polymorphique ; allèles = versions d'un même gène dans une espèce.
- Chromatides sœurs : 100 % identiques (réplication) ; homologues : 99,9 % (père / mère, variations de séquence) ; ex. allèle 1 du gène X sur le chromosome paternel (bleu), allèle 2 sur le maternel (rouge).
- Le polymorphisme résulte de mutations transmises ; types : substitution, délétion, insertion. Région codante : sans effet (substitution, dégénérescence, ex. GCC → GCG = Ala), changement d'aa (effet selon leur importance), décalage du cadre de lecture (le plus souvent perte de fonction). Région non codante (promoteur, 5'/3' non traduits, introns) : changement du niveau d'expression (site de fixation d'un facteur de transcription), défauts d'épissage (jonction intron/exon).
- Conséquences physiologiques : sans effet, différences entre individus, ou pathologie. Causes : erreurs de l'ADN polymérase lors de la réplication ; radiations ionisantes (ultra-violet, rayons X, radioactivité) ; certains agents toxiques.
- Mutation dans une cellule germinale non létale → transmise : nouveau polymorphisme, maladie génétique transmissible, avantage sélectif (évolution, sélection naturelle). Mutation dans une cellule somatique → non transmise : pathologie chez l'individu ; nombreuses mutations dans les cellules cancéreuses.
- Thérapie génique : introduire une copie normale d'un gène déficient. SCID : héréditaire récessive, rare (1/100 000), plusieurs gènes possibles (ex. ADA, enzyme du catabolisme des purines) ; défaut des lymphocytes ; déficience immunitaire sévère (enfant-bulle) ; traitement : greffe de moelle osseuse (cellules souches des lymphocytes) si donneur compatible. Thérapie génique de l'ADA-SCID : une trentaine de patients, amélioration clinique dans la majorité des cas ; inquiétude : émergence de cellules de type leucémique.
