### SÉQUENCE 3 — ASTUCE 1 : LA CONDENSATION  ·  *LA DIAPO DU COURS*

| | |
|---|---|
| **A. Durée** | 31 s (00:34 → 01:04) |
| **Source** | S1-2 p.31 — diapo `S1-2:31h` |

**B. Voix off**

> En préparation à la division, les chromosomes se condensent, ce qui facilitera leur séparation. Dans le noyau, l'ADN est associé à des protéines, principalement des **histones**.
>
> Tous les deux cents paires de bases environ, l'ADN s'enroule autour d'un complexe d'histones : c'est une succession de **nucléosomes**.
>
> Les queues des histones interagissent avec d'autres histones, ce qui rapproche les nucléosomes en une structure plus compacte. Avant la division, ces structures se replient encore et s'attachent à une armature de protéines : c'est le chromosome compact.
>

**C. Visuel à l'écran**

**D. Texte incrusté**

- Titre : **Astuce 1 : la condensation**
- ADN + protéines, surtout des **histones**
- Tous les ~**200 bp** : ADN enroulé autour d'histones = **nucléosome**
- Queues d'histones → compaction · repliements + **armature** → chromosome compact

### SÉQUENCE 6 — LE CARYOTYPE HUMAIN  ·  *LA DIAPO DU COURS*

| | |
|---|---|
| **A. Durée** | 33 s (01:27 → 02:00) |
| **Source** | S1-2 p.32 — diapo `S1-2:32b` |

**B. Voix off**

> Le **caryotype** : le classement des chromosomes, déjà répliqués, d'une cellule humaine en division.
>
> Les cellules humaines contiennent 23 chromosomes différents, n égale 23, présents en deux copies **homologues**, chacune reçue d'un parent.
>
> Les chromosomes homologues ont 99 % d'identité de séquence : ils contiennent la même information génétique, avec les quelques différences qui distinguent le père de la mère.
>
> Exception chez le mâle : l'homologue du X est remplacé par le chromosome Y. X et Y sont les **chromosomes sexuels** ; tous les autres sont les **autosomes**.
>

## 6. Récapitulatif des notions essentielles (fidèle au cours)

- Défi : chez les eucaryotes, plusieurs molécules d'ADN (chromosomes) entremêlées dans le noyau (chromatine, comme des spaghettis) ; chez l'homme, 46 chromosomes (23 de chaque parent) à répliquer puis distribuer.
- Première astuce, la condensation : ADN associé à des protéines, principalement des histones ; tous les ~200 bp, l'ADN s'enroule autour d'un complexe d'histones (succession de nucléosomes) ; les queues d'histones interagissent et rapprochent les nucléosomes ; repliements successifs et attache à une armature de protéines → chromosome compact.
- Deuxième astuce : après la réplication, les molécules d'ADN identiques restent attachées par les cohésines → chromatides sœurs.
- Chromosome condensé : centromère (chromatides sœurs attachées par les cohésines) ; télomères (extrémités des molécules d'ADN).
- Caryotype : classement des chromosomes répliqués d'une cellule en division ; 23 chromosomes différents (n = 23) en 2 copies homologues, chacune reçue d'un parent ; homologues : 99 % d'identité de séquence, même information génétique avec quelques différences ; exception chez le mâle : Y remplace l'homologue du X ; X et Y = chromosomes sexuels, les autres = autosomes.
- Ségrégation : séparation des chromatides sœurs (rupture des cohésines) réparties dans les deux cellules-filles ; microtubules accrochés de part et d'autre aux kinétochores (structures centromériques) ; chaque cellule-fille reçoit les homologues paternel et maternel.
