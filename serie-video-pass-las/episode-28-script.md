### SÉQUENCE 3 — DÉFINITION DU GÈNE  ·  *LA DIAPO DU COURS*

| | |
|---|---|
| **A. Durée** | 33 s (00:31 → 01:04) |
| **Source** | S1-3 p.2 — diapo `S1-3:2h` |

**B. Voix off**

> L'ADN contient toute l'information nécessaire au fonctionnement de l'organisme. Un **gène** est un segment d'ADN, de séquence déterminée, qui contient l'information nécessaire à la production d'un ARN de transfert, d'un ARN ribosomal, ou d'un ARN messager qui sera traduit en polypeptide.
>
> Il détermine ainsi une fonction cellulaire précise, et il a une localisation précise sur un chromosome : le **locus**.
>
> Chez l'homme : environ vingt mille gènes donnent des ARN messagers, et environ cinq cents donnent des ARNt et des ARNr.
>

**D. Texte incrusté**

- Titre : **Définition du gène**
- **Gène** = segment d'ADN → **ARNt**, **ARNr** ou **ARNm** (→ polypeptide)
- Fonction cellulaire précise · localisation précise = **locus**
- Homme : ± **20 000** gènes → ARNm · ± **500** → ARNt et ARNr

>
> La transcription, dans le noyau : l'ADN est recopié en ARN.

### SÉQUENCE 6 — POURQUOI DES TRIPLETS ?  ·  *LA DIAPO DU COURS*

| | |
|---|---|
| **A. Durée** | 21 s (01:38 → 02:00) |
| **Source** | S1-3 p.3 — diapo `S1-3:3b` |

**B. Voix off**

> Il faut traduire un ARN à quatre lettres en polypeptide à vingt lettres. Avec un nucléotide par acide aminé : seulement quatre possibilités. Avec deux : seize. Avec trois : soixante-quatre. C'est l'option du code génétique.
>
> Le code est lu par groupes de trois nucléotides : un **triplet** dans l'ADN correspond à un **codon** dans l'ARN, et un codon correspond à un acide aminé.
>

- 1 nt : **4** · 2 nt : **16** · 3 nt : **64** ← code génétique
- **Triplet** (ADN) ↔ **codon** (ARN) ↔ **1** acide aminé

## 6. Récapitulatif des notions essentielles (fidèle au cours)

- Chapitre VIII : 1. Définition du gène ; 2. Le code génétique ; 3. Synthèse des ARN messagers ; 4. Synthèse des protéines ; 5. Trafic des protéines ; 6. Contrôle de l'expression des gènes ; 7. Chez les procaryotes ; 8. Chez les virus ; 9. Gènes et génome ; 10. Mutations et polymorphisme. L'ADN contient toute l'information nécessaire au fonctionnement de l'organisme (livre à 4 lettres).
- Gène : segment d'ADN de séquence déterminée, contenant l'information nécessaire à la production d'un ARNt, d'un ARNr ou d'un ARNm traduit en polypeptide ; détermine une fonction cellulaire précise ; localisation précise sur un chromosome (locus). Chez l'homme : ± 20 000 gènes → ARNm ; ± 500 gènes → ARNt et ARNr. Ex. gène de l'insuline (INS) sur le chromosome 11 (NCBI Map viewer).
- Du gène à la fonction : transcription (noyau, recopiage de l'ADN en ARN) ; maturation (noyau, ARNm uniquement : épissage, modification des extrémités) ; traduction (cytoplasme, ARNm uniquement : synthèse peptidique selon le code génétique) ; ARNr et ARNt non traduits participent à la traduction.
- Code génétique : 4 lettres → 20 ; 1 nt = 4 possibilités, 2 nt = 16, 3 nt = 64 (option retenue) ; lu par groupes de 3 : triplet (ADN) ↔ codon (ARN) ↔ 1 acide aminé ; dégénéré (ex. valine : 4 codons) mais sans ambiguïté (un codon = un seul acide aminé) ; START AUG (méthionine : toute protéine commence par une méthionine) ; trois STOP : UGA, UAG, UAA ; tableau complet des codons.
