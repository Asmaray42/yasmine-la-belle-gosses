### SÉQUENCE 2 — L'INVASION DE L'ENDOMÈTRE  ·  *LA DIAPO DU COURS*

| | |
|---|---|
| **A. Durée** | 44 s (00:12 → 00:56) |
| **Source** | S2-1 p.22b — diapo `S2-1:22b` |

**B. Voix off**

> Le trophoblaste se différencie, d'abord du côté de l'adhésion, puis tout autour.
>
> Le **cytotrophoblaste** : couche interne, qui prolifère. Le **syncytiotrophoblaste** : couche externe, un syncytium, qui sécrète la h C G et est **invasif**, grâce à des protéases et des facteurs apoptotiques.
>
> Il envahit le stroma endométrial : c'est la **réaction déciduale**. Le stroma sécrète des facteurs qui favorisent l'embryon et contrôlent l'invasion ; il s'hypervascularise ; l'endomètre devient la **déciduale**.
>
> La circulation utéroplacentaire primitive se met en place : des **lacunes** se forment dans le syncytiotrophoblaste, les capillaires maternels sont érodés, et le sang s'écoule dans les lacunes. Après l'enfouissement complet, le trou de pénétration est bouché par un **caillot de fibrine**.

## 6. Récapitulatif des notions essentielles (fidèle au cours)

- Invasion : différenciation du trophoblaste (d'abord côté adhésion, puis tout autour) : cytotrophoblaste (couche interne, prolifération) et syncytiotrophoblaste (couche externe, syncytium, hCG, invasif : protéases, facteurs apoptotiques) ; envahissement du stroma → réaction déciduale (facteurs favorisant l'embryon et contrôlant l'invasion ; hypervascularisation ; endomètre → déciduale) ; circulation utéroplacentaire primitive (lacunes dans le syncytiotrophoblaste ; érosion des capillaires maternels, sang dans les lacunes) ; trou de pénétration bouché par un caillot de fibrine.
- Cavité amniotique : liquide entre épiblaste et trophoblaste ; couche issue de l'épiblaste = amnios, qui entourera entièrement l'embryon.
- Hypoblaste prolifère et tapisse le blastocèle → cavité exocœlomique (lécithocèle primaire, membrane de Heuser) ; mésoderme extraembryonnaire (cellules lâches) entre cytotrophoblaste et embryon ; cavités confluentes → cavité chorionique.
- Nouvelle migration de l'hypoblaste → vésicule ombilicale (lécithocèle secondaire) ; cavité exocœlomique fragmentée en petites vésicules (cavité chorionique, côté abembryonnaire) ; cavité chorionique ↑ → embryon pendu au pédicule suspenseur ; embryon = cavité amniotique + vésicule ombilicale + disque embryonnaire didermique.
- Villosités souches chorioniques : primaires (extensions du cytotrophoblaste dans le syncytiotrophoblaste), secondaires (+ mésoderme extraembryonnaire), tertiaires (+ vaisseaux) → circulation utéro-placentaire (le cœur commence à battre au jour 22) ; filtration par 4 couches : endothélium, mésoderme extraembryonnaire, cytotrophoblaste, syncytiotrophoblaste.

## 9. Mini-test de récupération active (corrigé détaillé)

> Une ou plusieurs propositions exactes. Réponds **avant** de lire le corrigé, puis refais le test 24 h plus tard.

### Question 1

Invasion :

- **A.** Le syncytiotrophoblaste produit la hCG.
- **B.** Le cytotrophoblaste est la couche externe.
- **C.** La réaction déciduale transforme l'endomètre en déciduale.
- **D.** Des lacunes se forment dans le syncytiotrophoblaste.
- **E.** Le trou de pénétration est bouché par un caillot de fibrine.

**✅ Réponse(s) : A, C, D, E**

- **A — VRAI.** p.22b.
- **B — FAUX.** Couche interne.
- **C — VRAI.** p.22b.
- **D — VRAI.** p.22b.
- **E — VRAI.** p.22b.

### Question 2

Cavités :

- **A.** La cavité amniotique se forme entre épiblaste et trophoblaste.
- **B.** L'amnios est issu de l'épiblaste.
- **C.** La cavité exocœlomique est entourée de la membrane de Heuser.
- **D.** La cavité chorionique se forme dans l'hypoblaste.
- **E.** La vésicule ombilicale est le lécithocèle secondaire.

**✅ Réponse(s) : A, B, C, E**

- **A — VRAI.** p.23h.
- **B — VRAI.** p.23h.
- **C — VRAI.** p.23b.
- **D — FAUX.** Dans le mésoderme extraembryonnaire.
- **E — VRAI.** p.24h.

### Question 3

Villosités :

- **A.** Les villosités primaires sont des extensions du cytotrophoblaste.
- **B.** Les villosités secondaires contiennent des vaisseaux.
- **C.** Le cœur commence à battre au jour 22.
- **D.** Les échanges sont filtrés par 4 couches.
- **E.** Le syncytiotrophoblaste fait partie des couches de filtration.

**✅ Réponse(s) : A, C, D, E**

- **A — VRAI.** p.25h.
- **B — FAUX.** Ce sont les tertiaires.
- **C — VRAI.** p.25h.
- **D — VRAI.** p.25b.
- **E — VRAI.** p.25b.
